# 🏨 Product Card Assignment (Airbnb-style UI)

This project is a **hotel product card** layout inspired by **Airbnb-style listings**, built using **HTML** and **CSS**. It focuses on replicating the structure and visual style of product cards used in hotel or property listings — such as image thumbnails, titles, prices, locations, and ratings.

---

## 📌 About

The purpose of this assignment is to:

- Practice **front-end layout techniques**
- Build a **realistic, card-based component** like those found on platforms such as Airbnb
- Understand spacing, positioning, and component styling using HTML and CSS

---

## 🎯 Features

- 🖼️ Hotel/property image
- 📍 Location details
- ⭐ Rating and reviews
- 💬 Description or features
- 💵 Price per night
- ✨ Hover effect on card (optional)

> 🧱 This version focuses on layout using **pure HTML and CSS only**, without any JavaScript.

---

## 🧰 Technologies Used

- **HTML5** – For structuring the product card
- **CSS3** – For styling, spacing, and layout
- *(No JavaScript or frameworks used)*

---

## 🧠 What I Practiced

- Card layout using Flexbox 
- Font styling, padding, margins
- Airbnb-style UI patterns
